# GitHub Pages version

Upload the contents of this folder to a GitHub repository and enable **Settings → Pages → Deploy from a branch**. Select the branch and `/ (root)`.

All asset paths are relative, so the site works at `username.github.io/repository-name/` without editing.

`profile.webp` is the optimized website image. `profile.jpg` is included as a widely compatible fallback and can also be uploaded directly as your GitHub profile picture.
